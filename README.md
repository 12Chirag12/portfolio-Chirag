# Chirag Patil — Portfolio

A responsive, dependency-free portfolio built with semantic HTML, modern CSS, and native JavaScript.

## Run locally

From this directory, start any static file server. For example:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Highlights

- Canvas-based ambient particle field with adaptive density
- Velocity-driven cursor physics and lightweight particle trail
- Magnetic call-to-action buttons, project spotlight, and restrained card tilt
- Responsive layouts and touch-specific fallbacks
- Full reduced-motion support
- Progressive-enhancement contact form powered by FormSubmit

No package installation or build step is required.
